# Мастер прогулов 80-го уровня

Сделано: лаба 1 (консольное приложение) и лаба 2 (Generic Host + DI - симуляция крутится бесконечно, день каждые 5 секунд).

| Команда | Что делает |
| --- | --- |
| `dotnet run` | Запустить симуляцию: новый день каждые 5 секунд |
| `Ctrl+C` / любая клавиша | Остановить программу |
| `dotnet build` | Собрать проект |
